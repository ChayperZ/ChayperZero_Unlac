## Overview | نظرة عامة

| English | العربية |
| :--- | :--- |
| **Chayper Zero** is a GUI application designed to decompile Lua bytecode into readable source code with a clean workflow focused on performance, clarity, and usability. | **Chayper Zero** هو تطبيق بواجهة رسومية مصمم لفك Lua bytecode وتحويله إلى كود مقروء ضمن بيئة عمل نظيفة تركّز على الأداء والوضوح وسهولة الاستخدام. |
| The project provides a modern interface, analysis-oriented layout, and support for handling files individually or in batches. | يوفّر المشروع واجهة حديثة، وتصميمًا مناسبًا للتحليل، ودعمًا لمعالجة الملفات بشكل فردي أو جماعي. |

## Features | المميزات

| Feature | English Description | الوصف بالعربية |
| :--- | :--- | :--- |
| High-Speed Decompilation | Fast and efficient Lua bytecode decompilation. | فك Lua bytecode بسرعة وكفاءة. |
| Modern Dark UI | Clean dark interface designed for comfortable use. | واجهة داكنة نظيفة ومريحة للاستخدام. |
| Side-by-Side Analysis | View hexadecimal data and Lua output together. | عرض بيانات Hex والكود الناتج معًا. |
| Batch Processing | Process multiple files or folders in one workflow. | معالجة عدة ملفات أو مجلدات ضمن نفس العمل. |

## Getting Started | البدء

| Step | English | العربية |
| :---: | :--- | :--- |
| 1 | Clone the repository. | استنساخ المستودع. |
| 2 | Install the required dependencies. | تثبيت المتطلبات اللازمة. |
| 3 | Run the main application file. | تشغيل الملف الرئيسي. |

| Command | Usage |
| :--- | :--- |
| `git clone https://github.com/ChayperZ/Chayper-Zero.git` | Clone repository |
| `cd Chayper-Zero` | Open project directory |
| `pip install -r requirements.txt` | Install dependencies |
| `python main.py` | Run application |
