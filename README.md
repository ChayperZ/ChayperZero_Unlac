## 🌍 Overview | نظرة عامة

| English | العربية |
| :--- | :--- |
| **Chayper Zero** is a high-performance GUI tool designed for reverse engineers to decompile Lua bytecode back into readable source code. | **Chayper Zero** هي أداة واجهة رسومية عالية الأداء مصممة لمهندسي العكس لفك تشفير "بيتكود" لووا وتحويله إلى كود مصدري مقروء. |
| It features a modern UI/UX, real-time analysis, and batch processing capabilities. | تتميز بواجهة مستخدم عصرية، وتحليل فوري للبيانات، وقدرات معالجة الملفات الجماعية. |

## 🚀 Getting Started | ابدأ الآن

| Steps (English) | الخطوات (بالعربية) |
| :--- | :--- |
| 1. **Clone Repo:** `git clone https://github.com/ChayperZ/Chayper-Zero.git` | 1. **تحميل المشروع:** انسخ الرابط واستخدم أمر Clone |
| 2. **Install:** `pip install -r requirements.txt` | 2. **التثبيت:** قم بتثبيت المكتبات اللازمة عبر الأمر |
